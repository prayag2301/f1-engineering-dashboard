# F1 Engineering Dashboard — Web

Next.js frontend application.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `NEXT_PUBLIC_API_URL` | API base URL (client-side) | `http://localhost:8000/api/v1` |
| `INTERNAL_API_URL` | API base URL (server-side) | `http://api:8000/api/v1` |
| `BACKEND_URL` | Backend proxy target | `http://api:8000` |
